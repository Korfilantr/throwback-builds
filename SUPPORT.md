# Throwback help and support

## Getting your Snapchat export

1. In Snapchat, open your profile → Settings (⚙︎) → **My Data**, or go to accounts.snapchat.com on the web.
2. Choose **Chat History** and **Chat Media**, and turn on **Export JSON Files**. Pick the date range you want (all time is fine).
3. Snapchat emails you when it's ready, usually within a few hours to a day.
4. Download **every part** (mydata~1.zip, mydata~2.zip, … or similar) to the Files app within about a week, before the links expire. Don't unzip them.
5. In Throwback, tap **Import my export**, select **all the parts at once**, tick the chats you want, and import.

Snapchat only exports chat photos and videos that someone **saved** in the chat. Snaps that disappeared aren't in the export.

## If the import says…

| Message | What to do |
|---|---|
| "only has web pages (HTML)" | Request the export again with **Export JSON Files** turned on. |
| "These are Snapchat Memories" | Throwback uses the My Data export with Chat History and Chat Media, not Memories. |
| "doesn't look like a Snapchat My Data export" | Pick the mydata zips from Snapchat's email. |
| "has your chats but no photos or videos" | Request the export again with **Chat Media** included. |
| "The first part of the export is missing" | Pick every part at once, including part 1. |
| "Part N of the export wasn't picked" | Choose the files again and select every part, or carry on without that part's clips. |
| "Snapchat seems to have changed the format" | Send the diagnostics log (below) so the app can learn the new format. |

## Importing a big export

Keep Throwback open while it imports. If you leave the app, the import pauses and keeps what it has done. Come back and tap **Continue**. Importing the same export again only adds what's missing; nothing is duplicated.

## Reporting a problem

In Throwback: Settings → Developer → **Report a problem**. Say roughly when it happened and what you did, then share the file it makes. The log has no names, chat titles or chat content.

## Contact

Open an issue at [github.com/Korfilantr/throwback-builds/issues](https://github.com/Korfilantr/throwback-builds/issues). Issues are public, so don't post personal information. Attach the diagnostics file instead of screenshots of your chats.
